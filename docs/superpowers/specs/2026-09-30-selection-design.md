# A2: исправить выделенное — дизайн

## Context
Фаза A исправляет только набранное с клавиатуры. Выделенный текст (например, вставленный или набранный давно) исправить нельзя. Spike показал: primary selection читается через data-control (cosmic-comp даёт `ext_data_control_manager_v1` и `zwlr_data_control_manager_v1` v2).

## Поток
1. Хоткей `Alt+Insert` (настраивается) перехватывается grab'ом; срабатывает после отпускания модификаторов, как остальные.
2. Движок возвращает `Action::ConvertSelection` и сбрасывает буфер (каретка сдвинется).
3. Демон читает primary selection (`wl-clipboard-rs`, таймаут 300 мс). Пусто/ошибка → ничего.
4. Таблицы раскладок: xkbcommon компилирует keymap из `xkb_config` (layout/variant); для каждой группы — `символ → Stroke { code, shift }` по уровням 0/1 печатных клавиш. Пересобираются при смене конфига.
5. `core::selection::convert(text, tables, current, unknown)`:
   - исходная группа — где набирается больше всего символов текста (ничья → текущая); целевая — следующая по кругу;
   - символ из исходной таблицы → её Stroke (под целевой раскладкой даёт нужную букву);
   - иначе из целевой → её Stroke (переносится как есть, напр. «№»);
   - `\n` → Enter, `\t` → Tab;
   - иначе (эмодзи): `Unknown::Keep` — пропустить, `Unknown::Abort` — отменить всё.
   Пустой текст или меньше двух раскладок → `None`.
6. Замена: `Backspace(1)` (удаляет выделение) → `SwitchLayout(target)` → `Type(strokes)`.

## Решения пользователя
- Символы вне раскладок: по умолчанию переносятся (`keep`), настройка `keep | abort`.
- Вставка через буфер обмена для эмодзи **не делается** (не работает в терминалах, где пользователь часто работает); при `keep` такие символы пропускаются с предупреждением в журнале.

## Ограничения
- Отката повторным нажатием нет: выделения уже нет.
- В терминале выделение не редактируемо: BackSpace сотрёт символ перед курсором, а не выделение. В терминалах — Insert/Super+Insert.
- Приложения без primary selection (часть Electron/XWayland) не поддерживаются.

## Конфиг и аплет
- `hotkey_selection` (по умолчанию `Alt+Insert`), `abort_on_unknown: bool` (по умолчанию `false` = keep).
- В аплете третье поле хоткея и переключатель «Отменять, если есть символы вне раскладок».

## Тесты
- `core`: convert — ru→us и us→ru, выбор исходной группы, перенос «как есть», `\n`, keep/abort, пустой текст, одна раскладка; движок — `Alt+Insert` даёт `ConvertSelection` и сбрасывает буфер, хоткей съеден.
- Вживую: gedit, терминал COSMIC, Firefox; выделение из обеих раскладок; многострочное выделение.
