# Внешний вид: попап как у штатного аплета + окно настроек — дизайн

## Context
Попап аплета выглядит чужеродно (радиокнопки, текстовые поля хоткеев с красной ошибкой). Пользователь хочет попап как у штатного `cosmic-applet-input-sources` и меню: системные настройки клавиатуры/языка и настройки программы. Настройки переезжают в отдельное окно (вариант B: тот же бинарник с `--settings`).

## 1. Попап
```
English (US)                  ← активная — жирным; клик переключает
us
Russian (Belarus)
by
──────────────────────
Исправлять раскладку   [●]
──────────────────────
Настройки клавиатуры…         → cosmic-settings keyboard
Регион и язык…                → cosmic-settings region-language
Настройки Lang Switch…        → cosmic-ext-lang-switch --settings
```
- Строки раскладок — `applet::menu_button(column[body(описание), caption(код)])`, как в input-sources; разделители `applet::padded_control(divider::horizontal)`.
- Если демон не запущен / нет доступа / нет протокола — первая строка попапа с предупреждением (текущие строки i18n).
- Кнопка в панели не меняется (метка раскладки, `·` при выключенном исправлении).

## 2. Окно настроек (`cosmic-ext-lang-switch --settings`)
- Разделы (`settings::section`): **Горячие клавиши** (слово, фраза, выделенное — кнопка с текущим сочетанием; «Сбросить по умолчанию»), **Поведение** (исправлять раскладку; не исправлять выделение с символами вне раскладок), **Состояние** (служба работает / что не так).
- Запись хоткея: клик по кнопке → «Нажмите сочетание…» → следующее нажатие допустимой клавиши (Insert, Pause, ScrollLock, Menu, F1–F12) с модификаторами сохраняется сразу; Esc отменяет; недопустимая клавиша — подсказка, запись продолжается. Сочетание, уже занятое другим действием, не сохраняется (подсказка).
- На время записи окно вызывает D-Bus `SetPaused(true)`: демон пересылает все клавиши и ничего не исправляет, иначе текущий хоткей до окна не дойдёт. После записи — `SetPaused(false)`. Демон снимает паузу сам через 30 с (окно могло закрыться посреди записи).

## 3. Код
- **daemon:** свойство `Layouts` → `a(sss)`: (метка, код раскладки, описание из `xkb-data`); метод `SetPaused(bool)` с авто-снятием через 30 с.
- **core:** `dbus.rs` — новые сигнатуры; `hotkey.rs` — `Hotkey::from_parts(mods, key_name)`/`KEY_NAMES` публично для записи из окна; `Hotkeys::conflict()`; `engine` — `set_paused`.
- **applet:** `main.rs` (выбор режима), `panel.rs` (попап), `settings.rs` (окно), `daemon.rs` (подписка D-Bus и вызовы). Строки en/ru.

## 4. Тесты
- Юнит: разбор записанного сочетания (имя клавиши iced → Hotkey), недопустимая клавиша, конфликт хоткеев, пауза в движке (всё пересылается, ничего не исправляется), подписи/описания раскладок.
- Вручную: попап рядом со штатным; все пункты меню; запись каждого хоткея, включая текущий Insert; сброс; Esc; конфликт.
